# 레이드 준비
{: .no_toc }

들어갈 맵을 고르면 진행 중인 퀘스트가 그 맵에서 요구하는 것을 모두 보여 줍니다.

## 맵 탭

맵 탭마다 남은 목표 수가 표시됩니다.

<!-- screenshot: map tabs -->

## 이 맵에서 진행되는 퀘스트

고른 맵에 목표가 있는 퀘스트와, 어느 맵에서나 할 수 있는 목표를 퀘스트별로 묶어 보여 줍니다.
퀘스트를 펼치면 다른 맵의 목표는 흐리게 표시됩니다.

<!-- screenshot: quests on the selected map -->

## 챙겨 갈 아이템 / 파밍할 아이템

- **챙겨 갈 아이템**(Bring with you): 이 맵에 설치할 아이템과 필요 수량·보유 수량
- **파밍할 아이템**(Items to loot): 이 맵에서 찾아야 하는 아이템

## 장비와 특수 조건

- **장비 · 무기**(Gear · Weapons): 필수·금지 장비와 허용 무기를 퀘스트별로
- **특수 조건**(Special conditions): 한 레이드 안에 완료, 특정 탈출구 사용 같은 규칙

{: .note-kr }
퀘스트 데이터에 맵 정보가 없는 목표는 목표 문장에 적힌 맵을 쓰고, **문장 기준**(from text)으로 표시합니다.
